# 8. Advantages & Disadvantages

## 8.1 Advantages

- Reduces the time required to create comics.
- Generates both stories and illustrations automatically.
- Allows users to customize their comics.
- Does not require professional drawing skills.
- Provides a simple web interface.
- Supports multiple art styles and story tones.
- Generates panel-by-panel comic content.
- Provides PDF export functionality.
- Combines text and image generation in one workflow.
- Modular architecture makes future improvements easier.

## 8.2 Disadvantages

- AI-generated content may not always match the user's exact expectations.
- Image generation can require significant computational resources.
- AI model/API availability may affect the application.
- API keys and external AI services must be configured correctly.
- The current version does not include user account management.
- The current version focuses on single comic generation.
- Generated content may require user review before final use.
