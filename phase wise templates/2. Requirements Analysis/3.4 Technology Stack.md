# 3.4 Technology Stack

## Table 1 – Components & Technologies

| S.No | Component | Description | Technology |
|---|---|---|---|
| 1 | User Interface | Provides the interface through which users enter their story prompt, character name, setting, tone and preferred art style and view the generated comic. | HTML, CSS, Jinja2 |
| 2 | Application Logic-1 | Handles user requests, form processing, routing, validation and coordination of the comic-generation workflow. | Python, FastAPI |
| 3 | Application Logic-2 | Generates a structured panel-by-panel comic outline from the user's story prompt. | Google Gemini Flash |
| 4 | Application Logic-3 | Converts the generated comic outline into detailed narration and character dialogues. | Google Gemini Pro |
| 5 | Application Logic-4 | Generates comic-style illustrations based on the image-generation prompts produced for each panel. | Stable Diffusion, Hugging Face Diffusers |
| 6 | Database | The current project does not specify a persistent database. User inputs and generated comic data are processed during the generation workflow. | Not specified / In-memory processing |
| 7 | Cloud Database | No cloud database is specified in the current ComicCraft implementation. | Not specified |
| 8 | File Storage | Stores generated panel images and exported PDF files. Generated images are stored in `static/panels` and PDFs in `static/exports`. | Local File System |
| 9 | External API-1 | Provides AI-powered generation of structured comic outlines from user prompts. | Google Gemini API |
| 10 | External API-2 | Provides AI-powered generation of detailed comic narration and character dialogues. | Google Gemini API |
| 11 | Machine Learning Model-1 | Generates structured comic panel outlines quickly based on user requirements. | Gemini Flash |
| 12 | Machine Learning Model-2 | Generates detailed creative narration and character dialogues. | Gemini Pro |
| 13 | Machine Learning Model-3 | Generates comic-style visual illustrations from image prompts. | Stable Diffusion v1.5 |
| 14 | PDF Generation | Combines comic images, panel titles, narration and other content into a downloadable PDF. | FPDF |
| 15 | Infrastructure (Server / Cloud) | Runs the FastAPI application and provides access to the web interface and API endpoints. | Uvicorn / FastAPI Local Server |

## Table 2 – Application Characteristics

| S.No | Characteristics | Description | Technology |
|---|---|---|---|
| 1 | Open-Source Frameworks | The application uses open-source technologies for backend development, frontend templating, image generation and PDF generation. | FastAPI, Python, Jinja2, Hugging Face Diffusers, Stable Diffusion, FPDF |
| 2 | Security | Sensitive AI credentials such as Gemini API keys and Hugging Face tokens are stored using environment variables instead of directly embedding them in application code. User input is processed through FastAPI form parameters and Pydantic validation for API requests. | Environment Variables, FastAPI Validation, Pydantic |
| 3 | Scalable Architecture | The application follows a modular architecture where frontend templates, FastAPI routes, AI generation modules, image generation, layout processing and PDF export are separated. This allows individual components to be enhanced or replaced independently. | FastAPI, Python Modules, Jinja2 |
| 4 | Availability | The application can be accessed through the FastAPI server when it is running. Uvicorn is used as the ASGI server, and FastAPI provides API endpoints that can be accessed through the application and API documentation. | FastAPI, Uvicorn |
| 5 | Performance | Gemini Flash is selected for fast structured comic-outline generation, while Gemini Pro is used for detailed creative content. The image-generation workflow uses Stable Diffusion, and the generated results are processed panel-by-panel. | Gemini Flash, Gemini Pro, Stable Diffusion, FastAPI |
