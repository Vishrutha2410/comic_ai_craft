## Non-Functional Requirements

| NFR No. | Non-Functional Requirement | Description |
|---|---|---|
| NFR-1 | Usability | The system shall provide a simple, interactive and user-friendly interface that allows users to create comics without requiring technical or artistic expertise. |
| NFR-2 | Security | The system shall protect sensitive API keys and configuration data using environment variables and should validate user inputs before processing them. |
| NFR-3 | Reliability | The system shall handle AI-generation and processing errors gracefully and provide appropriate responses when comic generation or export fails. |
| NFR-4 | Performance | The system shall efficiently process user prompts and generate comic outlines, narration, illustrations and PDF output within a reasonable response time. |
| NFR-5 | Availability | The application shall be accessible whenever the FastAPI server is running and shall provide both the web interface and API endpoints for comic generation. |
| NFR-6 | Scalability | The system architecture shall allow future expansion, such as user profiles, comic libraries and multi-page story arcs, without requiring major changes to the existing architecture. |
