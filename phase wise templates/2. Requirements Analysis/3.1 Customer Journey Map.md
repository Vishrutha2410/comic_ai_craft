### Steps and user experience

1. **Have a comic idea** – User wants to turn a story idea into a comic without drawing skills.
2. **Open ComicCraft** – User opens the web app in a browser.
3. **See the input form** – The form asks for story prompt, character name, setting, tone and art style.
4. **Write the story prompt** – Example: “A brave fox exploring an enchanted forest”.
5. **Name the hero and setting** – Example: a fox called Rusty in a forest, school or city.
6. **Choose tone and art style** – Tone can be dramatic or funny; style can be anime, comic book or realistic.
7. **Submit the form** – Data goes to the FastAPI backend through a POST request.
8. **Outline created** – Gemini Flash builds a five-panel outline containing number, title, scene and image prompt.
9. **Story written** – Gemini Pro adds narration and character dialogue to every panel.
10. **Images drawn** – Stable Diffusion creates a comic-style image per panel and saves it in `static/panels`.
11. **Comic preview** – `layout_builder.py` joins each image with its text and the preview page displays it.
12. **Review the preview** – User reads each panel and checks the images.
13. **Download the PDF** – `exporters.py` compiles images and narration into a PDF with FPDF and a timestamped name.
14. **Export success page** – User is redirected to `export_success.html`.
15. **Try a new tone or style** – The user can regenerate using a different tone or style.
16. **Share or print** – User saves, prints or shares the PDF.
17. **Start a new story** – User returns to the form with a fresh idea.

### Interactions and digital touchpoints

- Web browser on phone or desktop.
- `index.html` input form built with HTML, CSS and Jinja2.
- `/docs` page for API testing.
- Form text boxes and choices for the five inputs.
- Submit button sends the request.
- FastAPI backend receives form data or a JSON API call through `main.py` and `routes.py`.
- Gemini Flash: `generate_outline()` in `gemini_flash.py`.
- Gemini Pro: `generate_story()` in `gemini_pro.py`.
- Stable Diffusion / Diffusers: `generate_image()` in `image_generator.py`.
- `comic_preview.html` provides preview and download options.
- `exporters.py` / FPDF writes the PDF to `static/exports`.
- `export_success.html` confirms export.
- The saved PDF can be printed, emailed or shared through external applications.

### Goals and motivations

- Help users turn an idea into a comic without drawing.
- Help users understand what to enter.
- Help users describe their story clearly.
- Help users personalise the hero and world.
- Help users pick the right mood and look.
- Help users get a story that fits their idea.
- Help users see every scene drawn in their chosen style.
- Help users see the full comic quickly.
- Help users decide if they are happy with the comic.
- Help users save the comic in a format they can keep.
- Help users feel sure the download worked.
- Help users refine the mood and look.
- Help users share what they made.
- Help users start another comic.
