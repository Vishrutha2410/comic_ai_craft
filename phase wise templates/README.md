# ComicCraft – Phase Wise Templates

This folder organizes the content provided in the ComicCraft project document into seven project phases.

## Project
**ComicCraft – AI Comic Creator Using Gemini Models**

ComicCraft is an AI-powered web application that automates comic story and illustration creation using Gemini Flash, Gemini Pro and Stable Diffusion. The application uses FastAPI for backend operations and HTML, CSS and Jinja2 for the frontend. Users enter a story prompt, character name, setting, tone and art style, generate a five-panel comic, preview it and download it as a PDF.
